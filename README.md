# Online Shopping Mall

Bài thực hành theo nội dung CodeGym. Bootstrap 3.3.7.

## Chạy
Mở layout.html; cần Internet để tải thư viện CDN.

## Đề bài
https://internship.codegym.vn/learning/18/activity/1511

Dùng đúng navbar-inverse, panel và Glyphicons của Bootstrap 3. Có sáu sản phẩm, mỗi hàng ba ở desktop, giỏ hàng, ô Keywords và danh mục. Ảnh từ mẫu được đề dẫn: https://demo.codegym.vn/web/15/layout-bootstrap/.

## Kiểm tra
375, 768, 1440 px không tràn ngang; ảnh và font icon tải đúng. Tìm xyz cho 0 sản phẩm và thông báo; tìm Nokia hiện lại đủ 6.
